Pregunta 07 / Roles de QA

¿Cuál es la diferencia entre un QA funcional y un QA automatizador? ¿Qué tipos de herramientas utiliza cada uno?

Respuesta

El QA Funcional se enfoca principalmente en diseñar, ejecutar y documentar pruebas manuales para validar que el software cumpla los requisitos definidos por el negocio.

Por otro lado, el QA Automatizador desarrolla scripts y frameworks que permiten ejecutar pruebas de forma automática, aumentando la cobertura y reduciendo el tiempo necesario para pruebas repetitivas.

Herramientas utilizadas por un QA Funcional

  • Jira.
  • Azure DevOps.
  • TestRail.
  • Postman.
  • Navegadores web y DevTools.
  • Herramientas de gestión de evidencia y documentación.

Herramientas utilizadas por un QA Automatizador

  • Selenium.
  • Playwright.
  • Cypress.
  • Appium.
  • Postman para automatización de APIs.
  • Cucumber.
  • JUnit.
  • TestNG.
  • Git.
  • Jenkins.
  • GitHub Actions.
